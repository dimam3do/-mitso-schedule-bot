# Расписание МИТСО в Telegram Mini App

Бот показывает расписание твоей группы (с сайта apps.mitso.by) прямо внутри Telegram,
через кнопку "Открыть расписание" → мини-приложение. Данные каждый раз подгружаются
свежие с сайта университета (с кэшем на 10 минут, чтобы не спамить сайт).

## Как это устроено

- `scraper.py` — заходит на сайт МИТСО и вытаскивает расписание (как это делает браузер).
- `server.py` — веб-сервер (FastAPI): отдаёт JSON `/api/schedule` и само мини-приложение,
  а также держит бота живым в фоне.
- `bot.py` — Telegram-бот: команда `/start` присылает кнопку с мини-приложением.
- `webapp/index.html` — само мини-приложение (то, что видит пользователь в Telegram).

## Шаг 1. Проверь скрапер локально

```bash
pip install -r requirements.txt
python scraper.py
```

Если в терминале появится JSON с днями недели и парами — всё работает.
Если нет — открой `scraper.py` и подставь свои точные значения `fak`, `form`, `kurse`,
`group_class` (те, что ты видел(а) во вкладке Payload запроса `group-schedule` в DevTools).

## Шаг 2. Создай бота в Telegram

1. Напиши в Telegram боту **@BotFather**.
2. Команда `/newbot`, придумай имя и юзернейм (должен заканчиваться на `bot`).
3. BotFather пришлёт токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` — сохрани его.

## Шаг 3. Задеплой на Render.com (бесплатно)

1. Зарегистрируйся на [render.com](https://render.com).
2. Залей эту папку с кодом к себе на GitHub (создай новый репозиторий, загрузи туда файлы).
3. В Render: **New → Web Service** → выбери свой репозиторий.
4. Настройки:
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn server:app --host 0.0.0.0 --port $PORT`
5. В разделе **Environment** добавь переменные (те же, что в `.env.example`):
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather
   - `WEBAPP_URL` — после первого деплоя Render даст тебе адрес вида
     `https://твой-сервис.onrender.com` — впиши именно его сюда
   - `GROUP_FAK`, `GROUP_FORM`, `GROUP_KURSE`, `GROUP_CLASS` — данные твоей группы
6. Нажми **Deploy**. Через пару минут сервис будет запущен.
7. Если добавлял `WEBAPP_URL` уже после первого деплоя — сделай **Manual Deploy → Redeploy**,
   чтобы переменная подхватилась.

> Бесплатный тариф Render "засыпает" после ~15 минут без запросов. Это не страшно:
> при открытии мини-приложения он проснётся сам за 20-40 секунд.

## Шаг 4. Подключи мини-приложение к боту через @BotFather

1. Напиши **@BotFather** → `/mybots` → выбери своего бота.
2. **Bot Settings → Menu Button → Configure Menu Button**.
3. Пришли тот же URL, что в `WEBAPP_URL` (например `https://твой-сервис.onrender.com`).

Теперь у бота внизу будет кнопка меню, открывающая расписание, а также кнопка
"Открыть расписание" будет приходить по команде `/start`.

## Локальный запуск (для теста перед деплоем)

```bash
cp .env.example .env
# впиши в .env свой токен и данные группы, WEBAPP_URL можно оставить пустым для локального теста
pip install -r requirements.txt
uvicorn server:app --reload
```

Открой http://localhost:8000 в браузере — должно показаться твоё расписание
(Telegram-специфичные функции просто не будут работать вне Telegram, это нормально).

## Если сайт МИТСО обновит вёрстку

Скрапер завязан на конкретные CSS-классы (`weekly-schedule`, `table-responsive` и т.д.).
Если сайт изменит структуру страницы, `scraper.py` начнёт падать с ошибкой
"Не нашёл ни одного дня" — тогда нужно будет заново посмотреть в DevTools,
что изменилось, и поправить `parse_schedule()`.
